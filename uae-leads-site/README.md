# UAE home-services leads site (Next.js)
1. Install Node.js 20+. In this folder run: `npm install` then `npm run dev` and open http://localhost:3000
2. Edit `lib/site.js` (domain, WhatsApp number, email, prices, FAQ) and `lib/niches.js` (industry pages).
3. Deploy: push to GitHub, import the repo in Vercel, add your .com under Project > Domains, set the DNS records Vercel shows at your registrar.
4. After launch: add the site in Google Search Console, submit /sitemap.xml, add GA4.
